# Test-site
## Cupid's Bow

A little archery game in `index.html`: pull back the bow, pop flying hearts and pills to raise the heart rate to 180 BPM, then hit the last big heart to see the question.

- Open `index.html` in any browser. No build step.
- Add `#Name` to the end of the link to use a different name (e.g. `index.html#Sam`), or change `CONFIG.name` at the top of the script (currently Tudor).
