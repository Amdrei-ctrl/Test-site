# Test-site
## Cupid's Bow

A little archery game in `index.html`: pull back the bow, pop the flying hearts to fill the love meter, then hit the last big heart to see the question.

- Open `index.html` in any browser. No build step.
- Add `#Name` to the end of the link to personalise it (e.g. `index.html#Sam`), or set `CONFIG.name` at the top of the script.
